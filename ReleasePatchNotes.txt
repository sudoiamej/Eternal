Edition: PROFESSIONAL POWER-USER SUITE

--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------
Version 3.0.0 represents the ultimate transformation of Eternal into a premium, 
high-density technician's diagnostics and system recovery suite. This release 
integrates offline partition mounting, recursive driver injection, advanced BSOD 
dump analysis, a redesigned disk layout visualizer, and WUA thread fixes.

--------------------------------------------------------------------------------
NEW FEATURES & ARCHITECTURAL ENHANCEMENTS
--------------------------------------------------------------------------------

[TECHNICIAN RESCUE BELT] - OFFLINE SYSTEM TRIAGE
- OFFLINE REGISTRY MOUNTER: Load offline registry hives (`SYSTEM`, `SAM`, `SOFTWARE`) 
  from boot-failed OS drives directly within WinPE/WinRE.
- BOOT RECOVERY MACROS: One-click triage automation that resets startup driver states 
  (NVMe/SATA/AHCI) to recover systems locked in BSOD boot loops.
- DISM DRIVER INJECTOR: Recursively inject OEM controller or storage driver directories 
  (`.inf` / `.sys`) into active or offline target Windows images.
- BSOD MINIDUMP PARSER: Reads crash dump headers (`.dmp`) to extract BugCheck error codes 
  and trace third-party culprit drivers, with automated Knowledge Base advice.

[STORAGE & DISK MAP STUDIO] - TELEMETRY & LAYOUT
- PROPORTIONAL PARTITION LAYOUT: Repartition mapping visualizer dynamically scales 
  the width of partition cards proportional to their actual capacity on disk.
- SMART DIAGNOSTICS: Low-level bare-metal telemetry (Power-On Hours, Reallocated 
  Sector counts, and Predictive Failure flags) directly via WMI wrappers.
- VHD/VHDX VIRTUAL DISKS: Mount or detach virtual disk volumes natively.

[USER & SECURITY TRIAGE] - ACCOUNT RESCUE MANAGER
- ACCOUNT HEALTH METADATA: Track account lock status, last logon time, password age, 
  and Password Never Expires configuration state.
- FLUID GROUP BINDINGS: Checkbox bindings to quickly assign or revoke user groups 
  (Administrators, Users, Remote Desktop Users) with active lockout prevention locks.

[WINDOWS UPDATE STABILIZATION] - STA THREAD ISOLATION
- STA COM THREAD BINDING: Binds WUA (`Microsoft.Update.Session`) COM API calls to an 
  STA (Single-Threaded Apartment) thread, eliminating all MTA thread crashes on .NET 10.
- CONTEXTUAL FALLBACKS: Automatic backup queries utilizing WMI `Win32_QuickFixEngineering` 
  and CBS logs so update history displays instantly even if the update service is offline.
