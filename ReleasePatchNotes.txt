ETERNAL SYSTEM INTELLIGENCE - RELEASE NOTES
Version: 2.5.0 (Milestone 1)
Edition: CREATOR PLUS
Build Date: April 16, 2026

--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------
Milestone 1 of the 2.5.0 cycle introduces the "Registry Intelligence" suite,
providing unprecedented transparency and safety for low-level system configuration.
This update also features a significant overhaul of the Intelligence Dashboard
and improved resource resilience.

--------------------------------------------------------------------------------
NEW FEATURES & ARCHITECTURAL ENHANCEMENTS
--------------------------------------------------------------------------------

[REGISTRY INTELLIGENCE] - NEW MODULE
- SURGICAL UNDO VAULT: Automated, real-time backups for every registry change.
  Users can instantly revert modifications from a dedicated recovery panel.
- DRIFT WATCHLIST: Continuous monitoring of high-value registry paths (Startup,
  Shell Extensions). Visual alerts trigger when background drift is detected.
- BINARY PROVENANCE: The engine now identifies the "Owner" of registry keys,
  resolving GUIDs and paths back to their originating publisher and binary.
- VERSION-AWARE TWEAKS: Intelligent presets now automatically detect and 
  badge compatibility for Windows 10 vs. Windows 11.

[INTELLIGENCE DASHBOARD] - UI OVERHAUL
- HCI REFINEMENT: Layout restructured based on HCI principles (Affordances,
  Signifiers, Mapping) to reduce cognitive load and improve readability.
- SYSTEM PULSE: Enhanced focal health card with interactive detailed breakdown.
- COMPONENT GROUPING: Unified toolkits into "Creator Suite" and "Security Hunter"
  cards for better intent-based navigation.

[STABILITY & RESILIENCE]
- PACK URI ENFORCEMENT: Modernized resource dictionary loading with explicit 
  pack URIs to prevent StaticResource resolution failures during startup.
- ICON COMPATIBILITY: Standardized FontAwesome naming conventions to ensure
  full stability with the WPF 4.7 asset library.
- ERROR RECOVERY: Redesigned the splash screen and error handling to provide
  better diagnostic transparency during the boot sequence.
