ETERNAL SYSTEM INTELLIGENCE - RELEASE NOTES
Version: 2.5.0 (Milestone 2)
Edition: DEV PREVIEW
Build Date: April 18, 2026

--------------------------------------------------------------------------------
OVERVIEW
--------------------------------------------------------------------------------
Milestone 2 introduces "Components Diagnostics," a professional hardware testing 
suite. This update also transitions the platform to the modern Windows 26100 SDK, 
adds custom thematic branding, and significantly expands Thermal Intelligence 
with detailed GPU and power telemetry.

--------------------------------------------------------------------------------
NEW FEATURES & ARCHITECTURAL ENHANCEMENTS
--------------------------------------------------------------------------------

[COMPONENTS DIAGNOSTICS] - NEW MODULE
- HIGH-PERFORMANCE CAMERA: Low-level frame reader utilizing direct memory 
  copying (Bgr32) for smooth, real-time sensor verification.
- KEYBOARD NKRO VISUALIZER: Scaled, row-based physical layout for testing 
  anti-ghosting and N-Key Rollover limits.
- INTERACTIVE INPUT CANVAS: Precision path-plotting for Mouse, Touchpad, and 
  Touchscreen accuracy diagnostics.
- USB EVENT TRACKER: Real-time monitoring of the USB bus via WMI, logging 
  peripheral connection/disconnection events.

[THERMAL INTELLIGENCE] - EXPANDED TELEMETRY
- GPU INSIGHTS: Integrated Graphics telemetry for NVIDIA/AMD/Intel hardware.
- POWER & VOLTAGE: Live tracking of CPU Package Power (W) and Core Voltage (V).
- LOGICAL ANALYSIS: Intelligent thermal status engine that flags anomalies 
  (Throttling, High Drain) in plain language.

[APPEARANCE & BRANDING]
- DEV PREVIEW REBRANDING: Unified branding overhaul across splash screens, 
  headers, and log sequences.
- CUSTOM ACCENT COLORS: User-selectable theme colors with instant application 
  and session persistence via AppSettings.
- DATAGRID REFINEMENT: Overhauled global DataGrid styles for perfect dark-mode 
  readability and consistent header contrast.

[CORE ARCHITECTURE]
- SDK EVOLUTION: Upgraded target framework to .NET 10 with Windows 10.0.26100 
  support for native WinRT projection stability.
- SMART SUSPENSION: Components and sensors now automatically suspend when the 
  application is out of focus or minimized to reduce background resource drain.
